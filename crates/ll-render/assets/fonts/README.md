# Mitgelieferte Schriften

| Datei | Familie | Lizenz | Quelle |
|---|---|---|---|
| `D-DIN.otf`, `D-DIN-Bold.otf` | D-DIN | SIL Open Font License 1.1 (`OFL-D-DIN.txt`) | Datto Inc., https://www.datto.com/fonts/d-din (bezogen über fontsquirrel.com) |
| `D-DINCondensed.otf`, `D-DINCondensed-Bold.otf` | D-DIN Condensed | SIL Open Font License 1.1 | wie oben |

D-DIN ist eine freie Nachbildung der DIN 1451 (Schilderschrift, z. B. für Rohrleitungs-
kennzeichnung nach DIN 2403). Die Schriften werden in `ll_render::fonts` beim Start in die
Schriftdatenbank geladen und stehen wie Systemschriften zur Auswahl (ADR-042).
